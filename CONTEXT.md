# ScreenFling context

This glossary defines the terms that carry product meaning across ScreenFling.
Implementation details belong in code and architecture documents, not here.

## Workflow

One capture-to-result attempt. A workflow has one immutable operation ID and is
owned by the Electron main process.

## Operation ID

A UUID generated by the main process for one workflow. Every action that can
mutate that workflow carries the same ID. An action for any other ID is stale and
must not advance the workflow.

## Destination

A currently discoverable input surface plus its adapter, routing identity,
descriptive context, and capabilities. A destination is not a saved window title,
working directory, or application name.

## Routing identity

The exact tuple an adapter uses to address a destination: adapter, endpoint scope,
endpoint instance, surface kind, and surface locator. Descriptive context never
substitutes for this tuple.

## Context evidence

Observed labels such as working directory, repository, worktree, revision, or
agent type. Context evidence helps a person choose a destination but does not
address it.

## Revalidation

The adapter's check, immediately before dispatch, that the selected routing
identity still names the same live destination and supports the requested action.
Failure never falls back to the active or similarly named surface.

## Copy

Write the capture to the operating-system image clipboard. Copy makes no promise
about a destination.

## Stage

Place image and optional note input into an explicitly selected destination
without submitting it. ScreenFling reports only the evidence the adapter can
actually observe.

## Send

Submit through a versioned destination adapter that can verify both the exact
target and expected completion evidence. There is no generic press-Enter Send.

## Delivery result

The strongest evidence ScreenFling can report after an operation: copied,
dispatched-unverified, staged-verified, sent-verified, failed, or cancelled.

## Stale action

An action whose operation ID does not match the current active workflow, or whose
selected destination no longer revalidates. Stale actions fail closed and are not
retried automatically.
